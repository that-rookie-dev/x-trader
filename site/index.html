06 / Questions

Before you begin.

Does xTrader place trades for me?

No. xTrader is an analysis and instruction desk. Broker access is read-only. You make and execute every trading decision.

Can I use my existing paid AI account?

Yes. Create a provider profile in Settings, enter its API key, pick a model, live-test it, and activate it. Keys are encrypted and never shown again.

Can I avoid paid model APIs?

Yes. Run a model locally with Ollama or LM Studio, then connect xTrader to its local endpoint. No provider API key is required.

Is xTrader training the LLM every day?

No. It does not retrain the foundation model. It resolves each day’s predictions and tunes small, bounded per-symbol forecast deltas only when historical replay improves.

What happens when I remove a symbol?

It disappears from current scans and training views. Its historical data remains on your machine so it can be useful if you add the symbol again later.

How do updates work?

When a newer release is available, the app shows an update button. It applies the update, preserves your history and settings, and restarts.
